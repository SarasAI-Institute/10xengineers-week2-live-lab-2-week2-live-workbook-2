# Assessment 2 - Block 2: Custom AI Chat Agents

## Time Limit: 10 minutes

## Your Task

Create custom AI Chat instructions and specialized agents for this codebase.

## Instructions

1. Open this repo in Codespaces (or run locally)
   > 📖 Refer to "Student guide to use Continue as AI agent in Codespace.pdf" for setup instructions

> **Note:** Do NOT use the default GitHub Copilot Chat. Use Continue extension for AI Chat instead.

## Your Tasks

### Task 1: General AI Chat Instructions

Create `.continuerules` file with instructions that:
- Define coding style for this project
- Specify documentation requirements
- Set error handling patterns
- Define naming conventions

### Task 2: Documentation Agent

Create an agent that specializes in documentation. When activated, it should:
- Generate docstrings following a specific format
- Create markdown documentation
- Update README files
- Add inline comments

### Task 3: Code Review Agent

Create an agent that reviews code for:
- Potential bugs
- Performance issues
- Security concerns
- Style violations

## What You Should Learn

- Creating custom AI instructions for consistent code style
- Building specialized agent prompts for different tasks
- Testing and refining AI agent configurations
